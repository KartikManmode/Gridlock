# Project Planning & Architecture Documents

This directory contains all design blueprints, technology stack specifications, milestones, and progress summaries for **Project Gridlock**.

---

## Index of Planning Artifacts

1. **[`product_blueprint.md`](./product_blueprint.md):**
   The definitive product specification adapted directly from Claude's Master Blueprint: Product idea statement, In/Out MVP scope, proxy-data derivation rules, API contracts, and M1–M5 execution milestones.

2. **[`techstack.md`](./techstack.md):**
   Complete polyglot technology stack: React (MapLibre + deck.gl), Node.js (TypeScript), PostgreSQL (general data), MongoDB (ML predictions), and Architecture Decision Records (ADRs).

3. **[`roadmap.md`](./roadmap.md):**
   Unified execution roadmap synthesizing the project from data ingestion (M1) to operations workflow (M4) and polish (M5).

4. **[`Planning product blueprint and project design - Claude.pdf`](./Planning%20product%20blueprint%20and%20project%20design%20-%20Claude.pdf):**
   Original PDF blueprint from Claude (v0.2 Refactored).

5. **[`PROJECT_MAP.md`](./PROJECT_MAP.md):**
   Repository inventory mapping all directories to the system Data Flow Diagram and ERD.

6. **[`progress.md`](./progress.md):**
   Historical documentation tracking the ML evolution across Phases 1 through 5, culminating in the 93.087% SOTA model.
